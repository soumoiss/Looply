# Looply — entrega de 05/11/2026

O ZIP contém o projeto completo, incluindo frontend, Worker FCM, Android, banco e testes. Não há dados de usuários no pacote.

## Ordem de publicação

1. Faça backup/snapshot do Neon. Execute `migration/20261105_private_letters_silent_audit_and_passwords.sql` **uma vez**, em uma transação, na base Neon de produção. A migração preserva todas as cartas, mídias, leituras e eventos antigos. A política RLS deixa eventos antigos de desbloqueio invisíveis para o remetente.
2. Publique `backend/cloudflare/android-push-worker.mjs` no Worker FCM existente. O Worker bloqueia push de leitura/desbloqueio mesmo se a fila anterior ainda os entregar. O APK incluído também bloqueia esses dois tipos como defesa adicional, mas o Worker atualizado é necessário para os aparelhos já instalados.
3. Execute `npm test` e publique a saída de `npm run build` no GitHub Pages. A página usa o build ID automático para atualizar os assets do navegador.
4. Para a experiência nativa atualizada, compile o Android pelo fluxo já existente em `.github/workflows/`. Não substitua dados ou tabelas manualmente.

## Mudanças

- Cabeçalho translúcido, indicador animado na navegação inferior, entrada suave de páginas e modais, e alvos móveis ampliados, com respeito a movimento reduzido e tema global.
- Área exclusiva do ADM com horário de Fortaleza, usuário, carta e tipo de ação. Leitura/desbloqueio fora de Avisos e do push; aviso de carta nova continua disponível.
- Senhas não vazias de qualquer comprimento na criação, edição e abertura de cartas privadas. Senhas de login e de conta administrativa preservam suas regras próprias.
- Toast de chat com avatar autenticado, nome e prévia. Push Android usa nome/prévia confirmados no Neon e foto do cache privado do aparelho quando já disponível.
- Destaque de Why Now pela opção ✦ no visualizador do autor. O banco preserva o conteúdo após 24 h, mantém a audiência original e envia um aviso ao autor na primeira visualização do Highlight por cada pessoa. A deduplicação impede alertas repetidos.

## Verificação e limites

`npm test`: 931 testes aprovados. Sintaxe JavaScript verificada. A migração SQL foi revisada, mas não executada contra o Neon de produção neste pacote. Nenhuma publicação em GitHub Pages, Cloudflare ou APK foi feita por esta entrega; esses ambientes precisam receber os três componentes na ordem acima.
